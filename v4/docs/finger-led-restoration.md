# Superseded: finger LED restoration

RGB lighting was removed from the seeded v4 boards on 2026-09-16. That removal still describes `output_v4/seeded/`, which is now paused.

Per-key RGB is back in the design through the bought RGB key tiles, the hand breakout and the `pod_rgb` board. See [design status](design-status.md) and [key PCB quote options](key-pcb-quote-options.md). This document's original restoration plan for the flex finger boards is not being pursued.
