# Chassis-based Rosebear pipeline

[Design status](docs/design-status.md) lists the current decisions and open questions. It takes precedence over any other doc that disagrees with it.

## Current construction: key tiles

All 36 keys use bought 1U RGB key tiles, hand-wired per half to a generic FFC adapter, with 24-way FFC ribbons to a perfboard pod carrying the WT9932P4-TINY. LED power comes from the module's USB 5V. The first prototype needs no custom PCBs. [Key PCB quote options](docs/key-pcb-quote-options.md) covers the ribbon pinout and wiring, and the custom breakout and pod boards kept for a later build (generated by `v4/tools/build_key_quotes.py` into `output_v4/key-quotes/`).

The pointing device is open; a Cirque TM040040 trackpad is the likely choice. The editor's chassis does not model one.

## Browser chassis editor

Run `make v4-editor` and open **http://127.0.0.1:5177**. The editor builds the C64-styled case for the right hand from the key layout, with the tiles glued under the key plates and the ribbon leaving through a port panel on the inner end. The default case is the tape-deck prototype; the View panel's **Case shape (prototype)** select, or `?box=` in the URL, picks the other shapes. The [editor guide](editor/README.md) covers the layout parameters and handles, autosave, project files and the clearance checks. The FFC adapter's size is provisional (see design status).

KiCad/PCB generation stays offline. The Python chassis generator (`rosebear/chassis.py`) is kept as a numerical reference.

## Pod pin map

[`pod.json`](pod.json) is the only hand-edited pin map. It holds the WT9932P4-TINY header order, what each costly pin gives up (SD domain, UART0, JTAG, strapping), and the hand-chosen `fixed` groups (`trackball`, `rgb`). The seed assigns matrix and button pins from what remains and never takes a fixed group's GPIO, whether or not that group is built. `rosebear/pod_pins.py` stages these into the seed, checks the built pod against them, and writes `output_v4/pod-pins.json`, `pinout.txt` and `firmware-pinout.json`.

To move or add a hand-chosen pin, edit `pod.json` and rebuild. Don't edit pin numbers anywhere else.

## Paused: flex finger and flat thumb boards

The earlier custom-PCB pipeline (flex finger boards, flat thumb PCBs, LED-free pod, trackball board) is paused. `make v4` and `make v4-test` still build and test it, into `output_v4/seeded/`, using KiCad 10's Python and the BAML CLI; `v4/run --help` lists its options.

Trackball package geometry and sensor placement derive from [SparkFun's Blackberry Trackballer Breakout](https://github.com/sparkfun/Blackberry_Trackballer_Breakout), licensed [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); the reference files and attribution are in `reference/`, and derived trackball hardware is distributed under the same license.
